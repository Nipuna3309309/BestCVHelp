# BestCV Help page

Static help page for BestCV, published at https://sriqcorp.com/bestcv/help.
This URL is the **Help link** on the Partner Center Offer listing
(`BestCV-1/Partner Center Submission/03 Offer listing`).

Content comes from Doc 03 (*BestCV Privacy, Terms, Help and Support*), section 3 Help and section 5 AI transparency.
If you change the wording here, change Doc 03 too.

## Files

```
help/
├─ index.html     the page (no build step, no external scripts or fonts)
└─ assets/        logo, favicon and three screenshots from BestCV-1/Listing assets
```

## Publish

1. Upload the contents of `help/` so that `index.html` is served at `https://sriqcorp.com/bestcv/help`.
2. Upload the PDFs and release notes to `https://sriqcorp.com/bestcv/help/docs/` with these names (the Documents cards link to them):
   - `BestCV-Product-Overview.pdf`
   - `BestCV-Installation-and-User-Guide.pdf`
   - `release-notes.html`
3. Open the page in a private browser window and check every link, including privacy, terms and support.

## Before publishing

- Doc 03 marks the help wording as "match the final app". Check the button names (Write with AI, Generate image with AI, Publish to LinkedIn when I save, Save review, System instructions) against the released app.
- Support hours and the support, security and privacy mailboxes are values still to confirm in Doc 03.
